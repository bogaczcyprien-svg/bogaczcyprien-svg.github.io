# Portfolio BTS SIO SISR — Théo DURAND

Portfolio professionnel développé en HTML/CSS/JS pur, hébergé sur GitHub Pages.

## Structure

```
portfolio/
├── index.html              → Page d'accueil
├── presentation.html       → Présentation personnelle
├── bts-sio-sisr.html       → Description de la formation
├── veille.html             → Veille technologique
├── projets-patrimoine.html → Gérer le patrimoine informatique
├── projets-incidents.html  → Répondre aux incidents
├── projets-presence.html   → Développer la présence en ligne
├── projets-mode-projet.html→ Travailler en mode projet
├── projets-service.html    → Mettre à disposition un service
├── projets-dev-pro.html    → Développement professionnel
├── e6.html                 → Épreuve E6 (protégée par MDP)
├── css/style.css           → Feuille de style principale
├── js/nav.js               → Navigation partagée
└── pdf/                    → Documents PDF (à déposer)
```

## Déploiement GitHub Pages

1. Créer un repo GitHub (ex: `portfolio-bts`)
2. Uploader tous les fichiers
3. Settings → Pages → Source: main → Save
4. Votre site sera accessible sur `https://[username].github.io/portfolio-bts/`

## Mot de passe E6

Le mot de passe par défaut de la page E6 est : `E6-TechnoShop2025!`
Pour le changer, modifier la constante `PW_HASH` dans `e6.html`.

## PDF

Placer les documents PDF dans le dossier `pdf/` selon les noms indiqués dans `pdf/README.txt`.
