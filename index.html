Compétence E5

Gestion de parc informatique

Recenser, suivre, maintenir — savoir exactement ce qui tourne dans un SI c'est la base de toute administration efficace.

Pourquoi c'est indispensable
📋
Visibilité totale
Sans inventaire à jour, impossible de savoir ce qui tourne dans le SI. Une machine non répertoriée c'est une machine non sécurisée, non maintenue, non sauvegardée.
🔧
Maintenance proactive
Connaître l'état du parc permet d'anticiper les pannes, de planifier les remplacements et d'intervenir avant qu'un problème n'impacte les utilisateurs.
💰
Optimisation des coûts
Un inventaire précis évite les doublons, permet de réaffecter le matériel sous-utilisé et de justifier les investissements auprès de la direction.
📊
Suivi des licences
Savoir quels logiciels sont installés et sur combien de postes — essentiel pour rester en conformité légale et éviter les audits de licences surprise.

Curiosité & veille

Veille technologique

Une faille critique peut sortir un vendredi soir. Un outil qu'on utilise tous les jours peut sortir une mise à jour qui change tout. Dans ce métier, rester à jour c'est pas optionnel.

Comment fonctionne une veille efficace
📡
Choisir ses sources
Tout surveiller c'est impossible. Il faut sélectionner des sources fiables, complémentaires, adaptées à son domaine — et les consulter régulièrement.
🔍
Trier l'information
Distinguer ce qui est urgent (faille critique) de ce qui est intéressant mais non prioritaire. Ne pas se laisser noyer par le flux.
🧪
Tester avant d'appliquer
Pour les changements importants : tester sur une VM d'abord, valider le comportement, puis appliquer en production en toute confiance.
🔄
Partager & documenter
Une bonne info ça se partage. Ce qui concerne l'équipe est remonté, ce qui concerne le client est signalé — la veille individuelle devient collective.

Virtualisation – Proxmox et Hyper-V

Réalisation effectuée en cours de formation au CFA CCI de Saumur. Mise en place d'un environnement de virtualisation sur les serveurs de la salle TP pour héberger l'ensemble des VMs utilisées dans les situations professionnelles E6.

Contexte
  • Dans le cadre de la formation BTS SIO SISR au CFA CCI de Saumur, nous devions mettre en place un environnement virtualisé pour héberger nos serveurs de TP.
  • L'objectif était de maîtriser les deux hyperviseurs principaux du marché : Proxmox VE (type 1, open source) et Hyper-V (Microsoft).
  • Ces VMs ont ensuite servi de support aux situations professionnelles E6 (Windows Server 2022, Debian 12, poste client Windows 11).
Mise en œuvre
1. Installation de Proxmox VE
En formation, j'ai installé Proxmox VE depuis l'ISO sur un serveur physique de la salle TP. J'ai configuré l'interface web (port 8006), paramétré le réseau, les stockages (LVM) et créé les réseaux virtuels (vmbr0). Proxmox a ensuite hébergé toutes les VMs des situations E6.
2. Création des machines virtuelles
J'ai créé les VMs nécessaires aux TP : Windows Server 2022 (AD DS, serveur de fichiers, GPO — Situation 1 E6), Debian 12 (GLPI — Situation 2 E6), et un poste client Windows 11 pour les tests. Chaque VM a été configurée avec les ressources adaptées (vCPU, RAM, disque).
3. Configuration de Hyper-V
En cours de formation, j'ai activé le rôle Hyper-V sur Windows Server 2022 via le Gestionnaire de serveur. J'ai créé un commutateur virtuel externe pour la communication réseau et déployé des VMs Windows pour valider le fonctionnement de l'hyperviseur Microsoft.
4. Gestion des snapshots
J'ai pris des snapshots réguliers sur Proxmox avant chaque manipulation importante des serveurs, ce qui m'a permis de revenir à un état stable en cas d'erreur lors des configurations (AD, GPO, GLPI). Une bonne pratique acquise en formation et directement appliquée chez Scalesi.
Conclusion
Cette réalisation en formation m'a permis de maîtriser les deux hyperviseurs majeurs du marché. La pratique intensive de Proxmox au CFA m'a directement servi chez Scalesi où j'ai retrouvé cet outil chez plusieurs clients. La gestion des ressources virtuelles est aujourd'hui un réflexe dans mon travail quotidien d'administrateur systèmes.

Épreuve E5 — Réalisation professionnelle
🎓 Formation CFA

Configuration d'un serveur Windows – AD DS, DNS, DHCP, WSUS, DFS, Hyper-V

Réalisation effectuée en cours de formation au CFA CCI de Saumur. Déploiement complet d'un Windows Server 2022 avec les rôles AD DS, DNS, DHCP, WSUS, DFS et Hyper-V dans le cadre du contexte pédagogique TechnoShop.

Contexte
  • En formation BTS SIO SISR au CFA, nous avons travaillé sur le contexte pédagogique TechnoShop nécessitant une infrastructure Windows Server complète.
  • L'objectif était de maîtriser l'installation et la configuration des rôles serveurs principaux : AD DS, DNS, DHCP, WSUS, DFS et Hyper-V.
  • Cette réalisation est directement liée à la Situation 1 de l'épreuve E6 (AD DS, serveur de fichiers, GPO).
Mise en œuvre
1. Installation des rôles
Via le Gestionnaire de serveur, j'ai installé les rôles AD DS, DNS, DHCP, WSUS, DFS et Hyper-V sur la VM Windows Server 2022 hébergée sous Proxmox. J'ai promu le serveur en contrôleur de domaine pour le domaine technoshop.lan, configurant automatiquement le DNS intégré à AD.
2. Configuration Active Directory et DNS
J'ai créé l'arborescence des Unités d'Organisation (OU) : Commercial, Technique, Administration, Informatique. J'ai créé les comptes utilisateurs, les groupes de sécurité et configuré les zones DNS de recherche directe et inverse pour le domaine technoshop.lan.
3. Configuration DHCP, WSUS et DFS
J'ai configuré le DHCP (plage 192.168.1.50-200), mis en place WSUS pour centraliser les mises à jour Windows via GPO, et créé un espace de noms DFS pointant vers les partages du serveur de fichiers pour simplifier l'accès des utilisateurs.
4. GPO et partages NTFS
J'ai configuré les GPO (lecteurs réseau, blocage clé USB, politique de mot de passe) et sécurisé les partages NTFS par service avec des groupes RW et RO. Cette partie constitue le cœur de la Situation 1 de l'épreuve E6.
Conclusion
Cette réalisation en formation m'a permis de maîtriser l'ensemble des rôles Windows Server dans un environnement réaliste. Les compétences acquises ont été directement réutilisées chez Scalesi lors d'interventions sur les infrastructures clients, notamment pour la gestion des AD et des GPO.

Veille technologique — Windows Server & Active Directory

Windows Server
& Active Directory

Cette veille porte sur les évolutions de Windows Server et Active Directory, en lien direct avec ma situation E6 (déploiement d'un serveur de fichiers avec AD, GPO et sauvegarde chez TechnoShop via Scalesi).

01 — WINDOWS SERVER 2025

Nouveautés par rapport à Windows Server 2022

Windows Server 2025 est sorti en octobre 2024. Il apporte des améliorations importantes en sécurité et en administration Active Directory :

  • Kerberos armoring (FAST) activé par défaut — renforce l'authentification des utilisateurs AD (Kerberos est le protocole d'authentification réseau utilisé dans les domaines Windows)
  • SMB over QUIC — permet l'accès aux partages réseau sans VPN via internet, avec chiffrement intégré (SMB = Server Message Block, le protocole des partages Windows)
  • TLS 1.3 activé par défaut — TLS (Transport Layer Security) est le protocole de chiffrement des communications ; la version 1.3 est la plus sécurisée
  • NTLM désactivable via GPO native — NTLM est un ancien protocole d'authentification Windows vulnérable aux attaques par relais ; WS2025 facilite sa désactivation

Pour mes missions chez Scalesi, ces évolutions signifient que les migrations futures vers WS2025 apporteront un gain de sécurité significatif sans configuration supplémentaire.

02 — ACTIVE DIRECTORY & GPO

Bonnes pratiques et erreurs à éviter

Active Directory (AD) est l'annuaire centralisé de Windows qui gère les utilisateurs, les ordinateurs et les droits d'accès dans un domaine. Les GPO (Group Policy Objects) sont des règles appliquées automatiquement aux machines et utilisateurs du domaine (politique de mot de passe, blocage USB, mappage de lecteurs...).

  • Comptes inactifs : les comptes AD sans connexion depuis +90 jours doivent être désactivés — un compte inutilisé est une porte d'entrée potentielle pour un attaquant
  • Principe du moindre privilège : ne jamais donner plus de droits que nécessaire — éviter de mettre tous les admins dans le groupe "Domain Admins"
  • Politique de mot de passe : minimum 12 caractères (recommandation NIST 2024), complexité activée, historique des 10 derniers mots de passe — j'ai appliqué cela dans ma situation E6
  • GPO blocage USB : désactiver les ports USB en écriture pour éviter les fuites de données et les infections par clé malveillante — déployé chez plusieurs clients Scalesi
  • GPO verrouillage écran : verrouillage automatique après 10 minutes d'inactivité avec mot de passe — pratique simple mais souvent oubliée
03 — SAUVEGARDE WINDOWS SERVER

Windows Server Backup — Forces et limites

Windows Server Backup (WSB) est la solution de sauvegarde native intégrée à Windows Server, gratuite et sans licence supplémentaire. C'est l'outil que j'ai utilisé dans ma situation E6 pour la sauvegarde automatique quotidienne à 02h00 du serveur de fichiers TechnoShop.

✓ Points forts
  • Gratuit, inclus dans Windows Server
  • Simple à configurer (GUI ou PowerShell)
  • Sauvegarde du System State (AD compris)
  • Planification automatique quotidienne
  • Compatible VSS pour cohérence des données
⚠ Limites à connaître
  • Pas de sauvegarde incrémentielle fichier
  • Pas d'alerte email native en cas d'échec
  • Pas de console centralisée multi-serveurs
  • Occupe plus d'espace (pas de déduplication)
  • Recommandé pour 1-3 serveurs maximum

Pour des besoins plus avancés (plusieurs serveurs, RPO inférieur à 4h, restauration granulaire d'objets AD), des solutions tierces comme Veeam Backup & Replication sont recommandées.

04 — SÉCURITÉ & CVE

Vulnérabilités récentes et correctifs à appliquer

Une CVE (Common Vulnerabilities and Exposures) est un identifiant unique attribué à une faille de sécurité découverte dans un logiciel. Chaque CVE reçoit un score CVSS de 0 à 10 indiquant sa criticité : 7-8.9 = Élevé, 9-10 = Critique. Le suivi des CVE permet d'appliquer les correctifs prioritaires avant qu'un attaquant ne les exploite.
